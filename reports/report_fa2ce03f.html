Business Question: Which region generated the highest total sales, and which product contributes the most to it?

📊 Approach & Query

Query Code


SELECT 
  product_name,
  SUM(total_sales) AS product_sales
FROM region_product_sales_analysis
WHERE region = 'West'
GROUP BY product_name
ORDER BY product_sales DESC
LIMIT 10

Query Description

Aggregated total_sales by region using SUM() and GROUP BY to identify the highest-revenue region. Then filtered to the West region and aggregated by product_name to rank product contributions. The data was already pre-aggregated at the product-region level in the Gold table, so the analysis summed these values to get regional and product totals.
